# Dataset

El dataset utilizado es **Telco Customer Churn** disponible en Kaggle:

https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Instrucciones

1. Descarga el archivo `WA_Fn-UseC_-Telco-Customer-Churn.csv` de Kaggle.
2. Renómbralo a `telco_churn.csv`.
3. Colócalo en esta carpeta (`data/telco_churn.csv`).

El archivo **no está incluido en el repositorio** porque contiene datos de terceros.
